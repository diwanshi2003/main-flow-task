# main-flow-task

Task 1: Landing Page Development
# Objective:
Create a simple, responsive, and visually appealing landing page using HTML and CSS, 
featuring a hero section, dropdown navigation, key features, and a footer 

# Description:
This is a clean and modern responsive landing page designed to make a great first impression. At the top, you’ll find a sticky header with a logo and an easy-to-use navigation menu, including dropdowns for extra links. The hero section welcomes visitors with a bold headline, a short message, and a clear call-to-action button to get started.

Further down, there's a features section that highlights what makes the product or service stand out—like fast performance, mobile-friendly design, and a clean, user-friendly layout. At the bottom, a simple footer wraps things up with useful links like Privacy Policy and Terms of Service.

The page also includes some JavaScript to make the dropdowns interactive, so it feels smooth and intuitive to use on any device.
